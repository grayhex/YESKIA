# Личные данные S60

На страницах «Контакты», «Сообщения» и «Календарь» доступны чтение телефона,
поиск, просмотр полей и экспорт снимка JSON через системный диалог сохранения.
В календаре отдельно выбираются события и задачи. Снимки живут только в памяти страницы;
после ухода со страницы их нужно прочитать снова. SMS показываются с направлением,
датой и номерами частей составного сообщения; части пока не склеиваются.
Редактирование телефона, отправка SMS и синхронизация в этой версии не доступны.

## Подключение

Используется read-only часть `gammu_native.py` и `personal.py` из s60modern
(commit efaf53d), а не WPD. Нужны Python 3
с установленным python-gammu и работающий профиль Gammu под текущий порт и драйвер.
Выберите python.exe и профиль в раскрывающемся блоке настройки. Эта настройка общая
для трёх страниц и хранится до закрытия приложения. CLI-экспорт VCF/ICS через Gammu
также остаётся в настройках.

Worker использует только GetMemoryStatus/GetNextMemory (память ME),
GetCalendarStatus/GetNextCalendar, GetToDoStatus/GetNextToDo, GetSMSStatus/GetNextSMS.
Пустой список подтверждается явным нулевым счётчиком; неполное чтение и повтор позиции
считаются ошибкой. Ограничения: 5000 записей, 8 МиБ JSON, 180 секунд. Одновременное
чтение через этот адаптер блокируется. Кнопка «Отменить чтение» завершает worker. Вывод ошибок процесса не сохраняется в журнале.
Python и python-gammu не включены в установщик; собственный нативный NPC-адаптер
и поддержка конкретного E72 пока требуют отдельной аппаратной проверки.

## Аппаратная проверка

На Windows с E72 закрыть Nokia Suite и другие приложения, занимающие порт.
Проверить чтение каждого раздела, сопоставить количество и поля с телефоном;
проверить пустое хранилище, составное SMS, русские имена, повторяющиеся события,
отключение кабеля, неверный профиль и занятой порт. Проверить отмену диалога
экспорта и сохранение нового JSON без перезаписи существующего файла.
Личные данные в issues не публиковать.

## Каталог и сертификаты

В приложении есть локальный снимок метаданных каталога s60modern (без бинарников),
поиск, категории и подробности карточек. HTTP-сервис и доставка пакетов ещё не
подключены; кнопок фиктивной загрузки нет. Локальные SIS/JAR доступны отдельно
в «Моих установщиках»; наборы убраны из интерфейса.

Раздел сертификатов читает один публичный X.509 DER/PEM до 512 КиБ, показывает
владельца, издателя, даты на текущий момент компьютера и SHA-256. Доверие телефона
к сертификату не определяется. Проверка подписей SIS/SISX остаётся в инспекторе
локального установщика. Тестовый PEM — специально созданный публичный сертификат;
закрытый ключ не хранится.
