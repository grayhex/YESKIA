# Синтетические фикстуры

Файлы здесь — **вымышленные** (`synthetic: true`), для проверки анализатора и реплей-тестов. «Игрушечный» протокол
кадров `7E <длина> <команда> …` придуман и не связан с протоколами Nokia. Реальные (даже обезличенные) захваты сюда
не добавляются: `yeskia-lab scan` отвергает несинтетические фикстуры и любые `*.pcap`/`*.pcapng`/`*.etl`.

`*.golden.json` — эталонные результаты `yeskia-lab analyze` / `diff`; обновляются осознанно вместе с анализатором.
