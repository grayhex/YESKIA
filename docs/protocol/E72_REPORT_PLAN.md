# E72: анализ отчёта и дальнейшая проверка

Пользовательский отчёт: Nokia VID 0421/PID 0223, Windows 11, драйвер nmwcd,
один COM-порт и привязанный WPD с моделью E72-1, двумя хранилищами и 38 объектами.
Проверка WPD прочитала список. Состояние Doctor `com_present` при этом не означает,
что WPD отсутствует. Ранее выбор транспорта учитывал только состояние и выбирал COM,
из-за чего файлы и WPD-идентификация были недоступны. Теперь при наличии WPD выбирается
WPD; регрессионный тест воспроизводит одновременное наличие COM и WPD.

На Windows с тем же E72 проверить заново: найти устройство, подключить, убедиться в
модели E72-1 и изображении E72, открыть два хранилища и скопировать небольшой файл,
сверить содержимое, отключить кабель и подключить снова. Сохранить новый отчёт через
диалог и проверить отмену диалога. Без этих проверок исправление не подтверждено на телефоне.

## Контакты, календарь и SMS

Вместо внешнего Gammu реализован Rust-перенос нативного USB OBEX/PCCS из s60modern,
а для SMS — ограниченное чтение PDU через привязанный COM-порт. Python-worker,
выбор исполняемого файла и конфигурации удалены. Подробности протокола, ограничения,
сертификаты и аппаратный чек-лист — [личные данные S60](PERSONAL_WORKSPACE.md).

Чтение на E72 после переноса требует повторной проверки. Успешные синтетические
тесты не подтверждают реальное подключение или установку сертификата.
