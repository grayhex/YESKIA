# Текущий Fluent UI

Снимки из работающего React/Vite UI в Chromium, 1366×768, RU, явно помеченные
синтетические маршруты E72 и Developer mode. Это не физическая Nokia и не Windows
WebView2. Используется точный прозрачный логотип владельца, крупнее в шапке и меню.

- [Файлы: телефон](files-connected.png) · [без телефона](files-empty.png)

  новые прогоны обновляют отчёт автоматически.

Покрываются RU/EN, light/dark, 1500×900 и 1366×768, 100/150/200%, пустые/подключённые
устройства, read-only и длинные списки, несколько маршрутов, Developer Lab,
мастер подготовки, TLS и редактор контактов. Это эмуляция масштаба в браузере,
не аппаратная проверка Windows DPI. Отдельно проверяется первый кадр перехода
в тёмную тему с анимацией: светлых кнопок нет.

`npm run ui:layout` воспроизводит проверки и отчёт; CI публикует его артефактом.
Старые Nokia Classic/Soft UI скриншоты, HTML-прототипы и дорелизные Fluent снимки
удалены: они показывали другое оформление и устаревшие состояния.
