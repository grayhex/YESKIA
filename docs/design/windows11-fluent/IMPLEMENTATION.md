По уточнениям владельца градиент центральной карточки приглушён до графитово-синего,
а графический логотип заменён текстом. Поиск по всему приложению, аватар аккаунта,
макетные числа и неработающие команды не добавлены: существующая модель их не реализует.

## Размеры и прокрутка

Окно по умолчанию — **1500×900**, минимальное — **960×600** логических единиц.
При 1366×768 используется компактная компоновка с сохранением всех команд.
При уменьшении эффективной рабочей области панели перестраиваются; содержимое
доступно через одну прокрутку основной области, длинные списки — через свою панель.

Исправлены лишние 51 px прокрутки файлового менеджера после демо-баннера,
переполнение главной при 1366×768, пустой ряд под хранилищем копий и переполнение
боковой навигации. В начальных состояниях всех разделов на 1500×900 и 1366×768
нет вертикальной прокрутки основной области или навигации и горизонтального обрезания.
Каталог и длинные файловые списки прокручиваются внутри своих рабочих областей.
Длинные формы/отчёты и увеличенный масштаб сохраняют доступ к содержимому.

## Проверки

- `npm run ui:test` — 125 тестов.
- `npm run ui:typecheck`, `npm run ui:lint`, `npm --workspace ui run format:check`, `npm run ui:build`.
- `npm run ui:layout` — воспроизводимая проверка Chromium; [фактический JSON-отчёт](../../screenshots/fluent/layout-report.json).
- 1500×900 и 1366×768; RU/EN; light/dark; эффективные 100/150/200%; connected/empty/read-only, 100 файлов в каждой панели, onboarding, помощь и журнал разработчика.
- Проверяются body/main/sidebar overflow, загрузка изображений, наличие SVG во всей навигации и четырёх акцентов, E72 и текстовое название; длинные списки обязаны прокручиваться внутри обеих панелей.
- `cargo test -p yeskia-core -p yeskia-discovery -p yeskia-lab` — 283 теста; 9 интеграционных тестов FFmpeg запускаются только явно, см. [DEVELOPMENT.md](../../DEVELOPMENT.md).
- `cargo fmt --all --check`, `cargo clippy -p yeskia-core -p yeskia-discovery -p yeskia-lab --all-targets -- -D warnings`.
- `node --test scripts/release.test.mjs` — 9 тестов.

Для локальной проверки: `npm ci`, `npx playwright install chromium`, `npm run ui:layout`.
Системный `/usr/bin/chromium` используется при наличии; другой путь задаётся через
`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Скрипт сам запускает Vite на свободном порту
и закрывает процессы. Тестовая точка входа `ui/tests/layout` не входит в production build.
В CI проверка использует предустановленный Chrome образа `ubuntu-24.04`
через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`, без отдельного скачивания браузера
и повторной установки системных зависимостей. JSON публикуется артефактом.

[Фактические скриншоты](../../screenshots/fluent/README.md) получены из React UI с явной
демо-пометкой. Chromium-проверка эффективного масштаба не является проверкой реального
DPI Windows/WebView2 или доказательством работы физического телефона.
