# Windows-распространение (issue #11)

> Релиз **не публикуется автоматически**. Workflow собирает артефакты и оставляет их во вкладке запуска; GitHub
> Release создаёт владелец вручную после проверки и [ручной проверки на устройстве](release/MANUAL_CHECK.md).
> Сборки **не подписаны** сертификатом издателя: Windows SmartScreen может предупредить о неизвестном издателе.

## Артефакты

Собирает `scripts/package.sh` (в CI — задача «Windows app build + smoke», артефакт хранится 7 дней; вручную —
workflow «Release artifacts», 30 дней):

| Файл | Что это |
| --- | --- |
| `YESKIA_<версия>_x64-setup.exe` | установщик NSIS (Tauri), для текущего пользователя, **без прав администратора** |
| `YESKIA_<версия>_x64-portable.zip` | портативная сборка: `YESKIA.exe`, `yeskia.portable`, `README.txt` |
| `SHA256SUMS.txt` | SHA-256 всех файлов (`sha256sum -c SHA256SUMS.txt`) |
| `THIRD_PARTY_NOTICES.md` | лицензии компонентов, попадающих в сборку, и их тексты |
| `sbom.cdx.json` | SBOM CycloneDX 1.5 (Cargo + npm, с purl, лицензиями и хешами из lock-файлов) |
| `update.json` | манифест обновления для установщика (см. «Обновление») |
| `RELEASE_NOTES.md` | заметки: изменения из git и ограничения (подпись, устройство) |

Требования к чистой Windows 11 x64: **ничего** — ни Rust, ни Node, ни Python, ни Docker. Visual C++ Runtime не
нужен (статическая CRT, `.cargo/config.toml`). Нужен Microsoft Edge **WebView2 Runtime** — он входит в Windows 11;
приложение его не скачивает и не ставит, а при отсутствии показывает понятное сообщение с инструкцией и завершается.
FFmpeg (рингтоны и подготовка медиа) — отдельный необязательный инструмент пользователя, в сборку не входит.

## Установщик и удаление

- Режим `currentUser`: установка в профиль пользователя, права администратора не запрашиваются.
- **Объявленные изменения системы:** файлы программы, ярлык в меню «Пуск», стандартная запись удаления в
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall` и служебная запись пути установки в `HKCU`. Драйверы
  не устанавливаются, не заменяются и не удаляются; службы, задачи планировщика и автозапуск не создаются.
- **Данные пользователя** (настройки, журнал) — `%APPDATA%\dev.yeskia.app` (каталог по идентификатору приложения:
  именно его чистит галочка «удалить данные приложения» деинсталлятора Tauri). По умолчанию деинсталлятор данные
  **сохраняет**; удаляются только по отметке пользователя.
- **Резервные копии по умолчанию лежат вне каталога данных:** `Документы\YESKIA\Backups` — удаление данных приложения
  их не затрагивает. Папку можно выбрать на странице «Резервные копии». В портативном режиме копии — в `data\backups`.
- Ручная проверка поведения деинсталлятора (сохранить/удалить) — пункт [чек-листа](release/MANUAL_CHECK.md);
  в CI он не проверяется.

## Портативный режим

Файл `yeskia.portable` рядом с `YESKIA.exe` включает режим: настройки, журнал и копии — в подпапке `data`, профиль
Windows и реестр не используются. Переменная `YESKIA_DATA_DIR` (непустая) имеет приоритет. Удаление — удалить
папку (сначала скопируйте `data`, если она нужна). Ограничения: нужен WebView2; обновление — тем же ручным способом
(замена файлов); ярлыков и ассоциаций нет. CI запускает `--smoke-test` из распакованного ZIP и проверяет, что
создана подпапка `data`.

## Обновление

Приложение работает офлайн и **ничего не скачивает**. «Настройки → Обновление приложения»: вы получаете установщик
и `update.json` сами, приложение проверяет размер и SHA-256 по манифесту, версия должна быть строго новее текущей
(откат и повтор отвергаются), показывает ограничения и запускает установщик **только после подтверждения** и **не раньше,
чем завершены операции с телефоном и задания записи** (иначе обновление откладывается, установщик не запускается).
Файл повторно проверяется непосредственно перед запуском.

**Подпись.** Манифест может быть подписан Ed25519; доверенные ключи зашиты в `update::TRUSTED_KEYS`. **Пока ключ не
настроен (сейчас так), источник считается неподписанным:** интерфейс прямо пишет, что проверена только контрольная сумма,
что SmartScreen может предупредить, и требует отдельного согласия на запуск. Как настроить (решение владельца):

```bash
node scripts/release.mjs keygen --out ../update-private-key.pem   # приватный ключ хранить ВНЕ репозитория
# публичный ключ вставить в TRUSTED_KEYS (crates/yeskia-core/src/update.rs)
node scripts/release.mjs sign --key ../update-private-key.pem --manifest update.json --out update.sig
```

Совместимость подписи Node ↔ приложение проверяется тестом (`node_signature_verifies_in_rust`). Подпись манифеста
не заменяет Authenticode-подпись установщика: её нужно получить отдельно (сертификат издателя) и добавить в workflow —
до этого SmartScreen-предупреждение остаётся.

## CI и релиз

- `ci.yml`: Rust (fmt, clippy, тесты на Linux и Windows, FFmpeg для тестов медиа), UI (typecheck, lint, format, тесты,
  сборка, тесты скриптов релиза), Windows (сборка Tauri, smoke-тест, Doctor, **установщик + портативный ZIP + уведомления
  + SBOM + контрольные суммы**, проверка портативной сборки, проверка отсутствия HTTP-клиентов и внешних адресов в CSP).
- `release.yml`: только `workflow_dispatch`; права `contents: read`; публикации нет.
- Версия берётся из `src-tauri/tauri.conf.json`; для релиза поднимите её (и `workspace.package.version`) отдельным PR.

## Регрессионные сценарии

| Сценарий | Где проверяется |
| --- | --- |
| Чистая Windows без телефона | `crates/yeskia-discovery/tests/regression.rs` (пустой список, отчёт без идентификаторов); smoke и Doctor на раннере CI |
| WPD/MTP-only | `regression.rs`, `adapter.rs` (запись и PIM не заявляются; MTP ≠ PC Suite) |
| Mass Storage | `regression.rs`, `files.rs` (том ограничен устройством) |
| COM занят | `regression.rs`, `serial.rs` (ничего не «доступно», причина названа) |
| USB unplug | `regression.rs`, `adapter.rs`, `serial.rs`, `engine.rs` |
| Чужое MTP | `regression.rs`, `adapter.rs` (в список не попадает) |
| Отсутствие сети | `regression.rs` (`network_required = false`); CI: в сборке нет HTTP-клиентов/серверов, CSP без внешних адресов |
| Два телефона | `regression.rs` (разные идентификаторы, независимые соединения, отключение одного не трогает другой) |

Все они на **поддельной топологии**; на физических телефонах не выполнялись.
