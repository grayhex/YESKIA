# Установка и обновление Windows

## Один установщик

`scripts/package.sh` создаёт в `dist-release/` только
`YESKIA_<версия>_x64-setup.exe`. Portable ZIP, update.json, подписи манифеста,
SBOM и отдельные файлы контрольных сумм в артефакт больше не добавляются.
В CI и ручном workflow «Release artifacts» загружается только этот EXE.
GitHub оборачивает workflow artifact в ZIP при скачивании; внутри него один установщик.
В GitHub Releases можно прикрепить сам EXE, без архивирования.

Уведомления зависимостей генерируются во внутренней папке `build-support/`
и входят в установщик: `THIRD_PARTY_NOTICES.md`, `licenses/s60modern.txt`
и `licenses/PHONE_ARTWORK.md` устанавливаются рядом с приложением.
Лицензии не требуют отдельного скачивания. Служебные команды `release.mjs`
для SBOM/подписей сохранены для разработчиков, стандартная упаковка их не вызывает.

## Установка и данные

NSIS устанавливает приложение для текущего пользователя (`currentUser`) без запроса
прав администратора. Сохраняются идентификатор `dev.yeskia.app`, имя YESKIA и ключи
установки: новые сборки продолжают распознавать существующую установку.

Установщик создаёт файлы приложения, ярлык в меню «Пуск», запись удаления в
`HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\YESKIA` и служебный ключ
пути установки. Драйверы, службы и задачи автозапуска не устанавливаются.

Настройки и журнал хранятся в `%APPDATA%\dev.yeskia.app`. Резервные копии по умолчанию —
`Документы\YESKIA\Backups`; свою папку можно выбрать в приложении. По умолчанию
деинсталлятор сохраняет данные; их удаление выбирается отдельно пользователем.

Нужен WebView2 Runtime (есть в Windows 11). Rust, Node и Python для запуска оболочки
не нужны. Для подготовки медиа FFmpeg устанавливается отдельно; чтение PIM не требует Python/Gammu.

## Обновление тем же установщиком

Закройте приложение, скачайте новый `setup.exe` с
[GitHub Releases](https://github.com/grayhex/YESKIA/releases/latest) и запустите его.
NSIS определяет существующую установку и предлагает обновление/переустановку
с сохранением данных и прежнего каталога. Повторный запуск той же версии
поддерживается. В тихом режиме обновления откат на более старую версию запрещён
(`allowDowngrades: false`); интерактивный NSIS может предложить сначала удалить новую версию.

Кнопка «Настройки → Обновление приложения» открывает страницу релизов. Выбирать
манифест или подпись в приложении не требуется. Старый внутренний механизм проверки
локального манифеста не используется этим пользовательским сценарием.

Сборка пока без Authenticode-подписи; Windows SmartScreen может предупредить о
неизвестном издателе. Проверка подписи манифеста не заменяет подпись установщика.

## Проверки и выпуск

- CI: fmt, Clippy, Rust/UI/Python-тесты, сборка Tauri, smoke и Doctor без телефона.
- `scripts/test-installer.ps1` на изолированном Windows runner проверяет, что артефакт
  содержит ровно один установщик, выполняет установку, повторную установку и `/UPDATE`,
  проверяет версию в реестре, запуск установленного EXE, наличие лицензий и сохранность
  тестового файла в каталоге данных. Это проверка той же версии; переход между двумя
  выпущенными версиями остаётся отдельным пунктом ручного чек-листа.
- Ручной `release.yml` собирает и проверяет тот же EXE, без публикации.
- Для выпуска измените версию в `src-tauri/tauri.conf.json` и `workspace.package.version`
  в `Cargo.toml`, актуализируйте lock-файлы и версии npm при необходимости. Не задавайте
  другую версию только в имени артефакта.
- Публикация GitHub Release остаётся ручной после проверки. Существующие опубликованные
  файлы автоматически не удаляются.

Чистая Windows, SmartScreen, обновление с предыдущего релиза, удаление и физический
телефон проверяются по [ручному чек-листу](release/MANUAL_CHECK.md).

## Совместимость старых portable-сборок

Новые portable-сборки не выпускаются. Старый маркер `yeskia.portable` и переменная
`YESKIA_DATA_DIR` пока поддерживаются ядром для совместимости. Установщик не переносит
данные из старой portable-папки автоматически: сохраните её `data` и резервные копии
перед переходом на установленную версию.
