# Графика телефонов: происхождение и права

Иллюстрации перенесены из [grayhex/s60modern](https://github.com/grayhex/s60modern) (`symport/web_assets/phones`,
commit `efaf53d`, по заметкам `*-ARTWORK.md` и `README.md` рядом с файлами) по прямому указанию владельца репозитория.
Файлы лежат в `ui/src/assets/phones/`, реестр моделей — `ui/src/phones/registry.ts`.

## Как используется

- Иллюстрация выбирается по `Device.identified_model`, а до идентификации — по точному обозначению
  модели в имени карточки. Картинка не подтверждает соединение или доступность функций. VID/PID не используется.
- Подбор — точное совпадение обозначения (`E52`, `E52-1`, `N95 8GB`, …) без префиксного угадывания;
  неизвестная модель получает нейтральную графику. «N95» использует `nokia-n95.webp`,
  а «N95 8GB» — отдельную `nokia-n95-8gb.webp`.
- Карточка телефона использует иллюстрацию соответствующей модели. Декоративная коллекция на главной
  и в приветствии не обозначает обнаруженные устройства. Происхождение и оговорки о товарных знаках
  находятся в «О программе» и этом документе, без повторения под каждой картинкой.

## Статус прав (важно)

**Права на фото-производные иллюстрации не подтверждены.** Из заметок самого s60modern: эти изображения — «reference-based
image edits», то есть правки/генерации по сторонним фотографиям (GSMArena, предоставленные пользователями фото, Wikimedia
Commons), а не производственные ассеты Nokia и не собственные фотографии проекта; на корпусах видны знаки Nokia.
Лицензия MIT репозитория s60modern покрывает код и авторский вклад проекта, но не гарантирует прав на исходные фотографии
и товарные знаки. Это требование проверки из issue #2 («Проверить права на изображения/товарные знаки») остаётся
**открытым решением владельца**: оставить, заменить собственными схематичными SVG (как `nokia-n95-family.svg`) или
получить разрешение. Признак `rightsVerified: false` в реестре хранит это явно; схематичная SVG — единственная
оригинальная графика проекта.

## Что не переносилось намеренно

При переносе графики телефонов фирменные знаки `brand/*`, иконки `icons/*` и
`graphics.json` из s60modern не переносились (issue #2). Отдельно предоставленный
владельцем логотип YESKIA описан ниже.

## Полнота переноса для беты

Все 8 конкретных моделей из реестра s60modern представлены в YESKIA: E52, E72, N95,
N95 8GB, N97 mini, N8, E7 и 7610. Всего 9 растровых изображений, включая открытый E7.
PNG-дубликаты и SVG с встроенным растром повторно не поставляются.
Схематичный `nokia-n95-family.svg` больше не выбирается для карточки N95.

Полные SHA-256 исходников и поставляемых изображений: `ui/src/phones/artwork-manifest.json`.
При сверке PNG → WebP проверены размеры и точное совпадение изображения на белом и чёрном
фоне (включая прозрачность). Выбор изображения в карточке покрыт тестами для всех 8 моделей,
отдельно — приоритет подтверждённой модели и неизвестное устройство.

## Логотип YESKIA

`ui/src/assets/brand/yeskia-logo.png` — точный исходный PNG 2172×724 с прозрачностью
из [ссылки владельца](https://chatgpt.com/s/m_6af4c40b0af881918c335f6cd599fe98),
полученный 2026-11-11. Он заменяет прежний логотип по прямому запросу владельца.
В приложении используется локально в боковом меню; сетевой загрузки при запуске нет.
Значки Windows также созданы из этого исходника командой `npm run tauri icon -- --fit contain`.
