# YESKIA 0.5.0 — кандидат для проверки

Windows 11 x64, WebView2; Rust/Node/Python не нужны для установленного приложения.
Версия собирается явно как AMD64 Windows GUI `yeskia-app.exe`; пользователь скачивает
один `YESKIA_0.5.0_x64-setup.exe`. Сначала используйте успешный CI artifact; пустой
prerelease 0.1.0 не содержит установщика. Публикация нового GitHub Release ручная.

## Проверка на стенде владельца

1. Установите EXE, отключите MOCK при необходимости. Светлая тема по умолчанию;
   переключите на тёмную и перезапустите: выбор сохранён, белых кнопок нет.
2. Сопрягите E72 и наушники в Windows. Откройте/обновите список: предлагается только
   телефон класса Phone; discovery не должен подключаться к наушникам или телефону.
3. Bluetooth: запустите rshelld на Nokia, выберите её маршрут, явно подключитесь.
   Сначала ping/list/read небольшого файла, сохраните hash. Системные операции не нужны.
4. USB: PC Suite для native PIM, MTP/WPD для чтения файлов, накопитель для связанного
   тома. Сначала чтение, затем новая тестовая папка/файл с read-back на резервной карте.
5. Контакты: сначала снимок, экспорт и локальная книга. Записи на Nokia пока нет;
   не ожидайте синхронизации, Create/Update/Delete или отправки SMS.
6. TLS: импортируйте официальные пакеты, проверьте пины, используйте ручные шаги,
   сохраните оригинальный DLL до изменения. Экспортируйте TLS report; host/manual
   состояния не становятся аппаратным подтверждением.
7. При сбое записи не повторяйте её до проверки телефона. Сохраните Doctor/отчёт
   без IMEI, MAC, PnP identifiers, номеров, содержимого сообщений и личных файлов.

По каждому тесту запишите модель/RM/прошивку, Windows/драйвер/режим, версию YESKIA,
действие, результат, checksum и отключение/повторное подключение. Чек-листы:
[релиз](MANUAL_CHECK.md), [агент](../agent/WINDOWS_E72_CHECK.md),
[личные данные](../protocol/PERSONAL_WORKSPACE.md). Не публикуйте raw phone dumps.

## Проверки сборки

```bash
npm ci
npm run release:check
npm run release:test
bash scripts/package.sh
# target/x86_64-pc-windows-msvc/release/yeskia-app.exe
# dist-release/YESKIA_0.5.0_x64-setup.exe
```

CI проверяет installed executable/hash/version/architecture, повторную установку,
UPDATE и сохранение данных. Он не заменяет чистую Windows, реальный UI/радио,
обновление между двумя выпущенными версиями или испытания на телефоне.
