# YESKIA 0.1.0 — первое закрытое бета-тестирование

Бета предназначена для проверки подключения Nokia на Windows 11 x64. Поддержка конкретной модели
ещё не подтверждена физическими тестами. Сначала проверяйте чтение; используйте копии файлов.

## Начало работы

1. Скачайте единственный `YESKIA_<версия>_x64-setup.exe` из релиза и запустите его.
   Для обновления установленной версии закройте YESKIA и запустите новый установщик.
   WebView2 входит в Windows 11.
2. Сборка не подписана издателем: Windows может показать предупреждение SmartScreen.
   Скачивайте установщик со страницы релизов проекта. Драйверы автоматически не устанавливаются.
3. Отключите демо-устройство в настройках, если оно было включено. Подключите разблокированный
   телефон исправным кабелем USB с передачей данных. Закройте Nokia PC Suite и другие программы,
   которые могут занимать телефон или его COM-порт.
4. Для файлов выберите на телефоне «Передача данных / MTP» или «Накопитель».
   Откройте «Подключение», обновите список, нажмите «Подключить» рядом с найденным устройством.
5. Если телефона нет в списке, откройте «Подключение → Диагностика». Проверьте кабель, режим USB и драйвер
   в Диспетчере устройств Windows. Сохраните отчёт кнопкой «Сохранить отчёт».

## Что проверять

| Режим | Доступная реализация | Первый тест |
| --- | --- | --- |
| MTP/WPD | Список папок и скачивание, без записи | Открыть папку, скачать небольшой файл, сравнить SHA-256 с оригиналом |
| Накопитель | Чтение и запись на связанный с телефоном том | Сначала скачать файл; запись — только в новую тестовую папку на резервной карте |
| Виртуальный COM / AT | Идентификация и счётчики поддерживаемых хранилищ | Идентифицировать телефон; доступность зависит от ответов устройства |
| Nokia PC Suite / NPC, OBEX | Не поддерживаются | Не ожидать синхронизации контактов, SMS и установки приложений |

Передача SIS/JAR означает копирование файла, а не установку на телефоне. Резервная копия сохраняет
файлы, а не всё содержимое телефона. Не проверяйте запись на единственном экземпляре важных данных.
При неизвестном результате записи проверьте файл на телефоне перед повтором.

## Для сопровождающего: условия выдачи бета-сборки

На Windows выполните CI `windows-app`: сборка оболочки, smoke-test, Doctor без телефона,
упаковка, установка и проверка переустановки/режима обновления. Локальный эквивалент (Git Bash, Node >=20, Rust stable,
MSVC Build Tools и WebView2):

```bash
npm ci
npm run ui:build
cargo build --locked -p yeskia-app --release
YESKIA_DATA_DIR="$PWD/target/beta-smoke" ./target/release/yeskia-app.exe --smoke-test
./target/release/yeskia-app.exe --doctor
bash scripts/package.sh
# dist-release/ содержит только setup.exe
```

Затем проверьте установку и обновление с предыдущей версии на чистой Windows по `MANUAL_CHECK.md`.
Сборку Windows, SmartScreen и реальный USB в Linux не проверяли. До этих проверок это кандидат
на закрытую бету, не подтверждённый аппаратный релиз. Проверка прав на графику остаётся открытой
задачей владельца; происхождение зафиксировано в `docs/ASSETS.md`.
