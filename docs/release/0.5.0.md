# YESKIA 0.5.0 — предварительный релиз

Целевой installer: `YESKIA_0.5.0_x64-setup.exe`.
Приложение внутри: AMD64 Windows GUI `yeskia-app.exe`, runtime version 0.5.0.

Содержит Native ADBian/Device Lab, локальные контакты, TLS Revival с privacy report,
мастер E72, явные темы/крупный логотип и обновлённую компоновку подключения.
Данные и installation identifier сохранены; новый бинарник проверяется по версии,
архитектуре и installed/build SHA-256.

CI и ручной Release artifacts вызывают **один reusable Windows workflow**:
version/target gate → build → smoke/Doctor → NSIS → install/reinstall/UPDATE →
проверка установленного EXE → один artifact. Отсутствие свежего EXE или подмена
версии/архитектуры/console subsystem останавливает упаковку.

CI не публикует тег/Release автоматически. Для ручной приёмки использовать
[MANUAL_CHECK.md](MANUAL_CHECK.md). Переход с опубликованного 0.1.0 нельзя считать
проверенным по одному reinstall: тот prerelease не содержал setup.exe.
Аппаратная приёмка E72 и writable contacts остаются отдельными открытыми задачами.
