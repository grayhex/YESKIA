# YESKIA

Приложение для Windows 11 x64 для работы с Nokia на S60 и Symbian. Файлы,
контакты, сообщения, календарь и инструменты для старых телефонов в одном окне.
Основные операции работают локально, без аккаунта и сервера.

## Скачать и установить

На странице [последнего релиза](https://github.com/grayhex/YESKIA/releases/latest)
скачайте **`YESKIA_<версия>_x64-setup.exe`** и запустите его. Это единственный файл,
который нужен для установки. Права администратора не требуются.

Для обновления закройте YESKIA и запустите новый установщик: он обнаружит текущую
установку и обновит приложение в той же папке. Настройки, журнал и резервные копии
сохраняются. Тот же установщик позволяет повторно установить текущую версию.
Кнопка обновления в настройках открывает страницу релизов.

Требуется WebView2 Runtime (обычно уже есть в Windows 11). Сборки пока не подписаны
сертификатом издателя, поэтому Windows может показывать предупреждение SmartScreen.

## Возможности

- **Телефон и подключение:** поиск USB/WPD/COM-устройств, подключение, диагностика
  и сохранение отчёта через системный диалог.
- **Файлы:** две панели «Компьютер / Телефон», скачивание через WPD/MTP;
  чтение и запись на связанный с телефоном том в режиме накопителя.
- **Контакты, сообщения, календарь и задачи:** чтение напрямую из Rust по USB OBEX/PCCS и COM/PDU, поиск,
  просмотр записей, отмена чтения и экспорт JSON. Python и Gammu не нужны. Запись контактов и отправка SMS ещё не доступны.
- **Приложения:** 40 карточек каталога s60modern с поиском и категориями.
  Подключение веб-каталога и загрузка пока готовятся. Свои SIS/SISX/JAR/JAD
  можно открыть и проверить в разделе «Мои установщики».
- **Сертификаты:** сведения о публичных CER/DER/PEM, сроки действия и SHA-256;
  проверка подписей SIS/SISX в инспекторе установщиков. Передача сертификата
  для установки с подтверждением на телефоне.
- **Медиа и темы:** подготовка рингтонов и медиа через внешний FFmpeg,
  анализ и предпросмотр ресурсов тем S60.
- **Резервные копии:** создание файловых копий, проверка и восстановление.

Это бета. Поддержка операций зависит от модели, драйвера и режима USB.
Успешное обнаружение телефона не подтверждает доступ ко всем его данным.
Подключение и чтение на физическом E72 требуют повторной проверки;
сценарии описаны в [инструкции тестирования](docs/release/BETA_TESTING.md).

## Начало работы с телефоном

1. Подключите разблокированный телефон USB-кабелем с передачей данных.
2. Для файлов выберите на телефоне MTP/передачу данных или режим накопителя.
3. В разделе «Подключение» найдите телефон и нажмите «Подключить».
4. Если подключение не получилось, откройте там же «Диагностику» и сохраните отчёт.
5. Для контактов, сообщений и календаря выберите на телефоне режим PC Suite.
   Закройте программы, занимающие телефон, и нажмите «Прочитать телефон»
   в нужном разделе. [Поддерживаемые маршруты](docs/protocol/PERSONAL_WORKSPACE.md).

Драйверы автоматически не устанавливаются. Передача SIS/JAR на телефон означает
копирование файла; установку нужно подтвердить на самом телефоне.

## Разработка

Стек: **Tauri 2 + Rust + React/TypeScript**. Для сборки на Windows нужны Node.js 22,
Rust stable MSVC и Visual Studio Build Tools с C++.

```bash
npm ci
npm run tauri dev
# Один готовый установщик в dist-release/
bash scripts/package.sh
```

Версия установщика берётся из `src-tauri/tauri.conf.json`; она должна совпадать
с версией приложения в `Cargo.toml`. CI проверяет ядро и интерфейс, собирает
установщик, выполняет установку, повторную установку и запуск в режиме обновления.
Уведомления о лицензиях входят в установку; portable, манифесты и служебные отчёты
рядом с установщиком не выпускаются.
