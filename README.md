# YESKIA

Локальное приложение для **Windows 11 x64** и Nokia S60/Symbian: файлы телефона,
офлайн-книга контактов, чтение PIM, пакеты, TLS/HTTPS и подготовка E72. Tauri 2,
Rust и React; аккаунт, сервер, Python, Gammu и Docker для запуска не нужны.

## Сборка и установка

Предварительный релиз — **0.5.0**. Файл для пользователя:
[**`YESKIA_0.5.0_x64-setup.exe`**](https://github.com/grayhex/YESKIA/releases/download/0.5.0/YESKIA_0.5.0_x64-setup.exe). Он устанавливает `yeskia-app.exe`, а не CLI
лаборатории или телефонный SIS-агент.

Проверенные сборки доступны в [успешных запусках CI](https://github.com/grayhex/YESKIA/actions/workflows/ci.yml)
как `YESKIA-Windows-Installer`. GitHub скачивает workflow artifact в ZIP, внутри
которого один setup.exe. Артефакты CI имеют срок хранения. В опубликованном
предварительном релизе `0.1.0` нет файлов; актуальная версия доступна на [странице релизов](https://github.com/grayhex/YESKIA/releases).

Установка для текущего пользователя не требует администратора. Для обновления
закройте YESKIA и запустите новый setup.exe: каталог установки и данные сохраняются.
Лицензии входят в установку. Нужен WebView2 Runtime, обычно уже имеющийся в Windows 11;
FFmpeg устанавливается отдельно для медиа. Сборки пока без Authenticode-подписи.

## Что работает

| Раздел | Реализация и границы |
| --- | --- |
| Подключение | Автообнаружение USB и сопряжённых Bluetooth-телефонов, явное подключение выбранного устройства, Doctor и обезличенный отчёт. Аудиоустройства не предлагаются как телефоны. |
| Файлы | Две панели, поиск, сортировка, клавиатура, копирование, коллизии, очередь и отмена. WPD/MTP — чтение; Mass Storage — чтение/запись. ADBian — C:/E:/Z:/ только после успешного ответа, Z: только чтение, запись с read-back. |
| Контакты | Полная локальная книга, VCF 2.1/3/4 и CSV, сопоставление колонок, UTF-8/UTF-16/Windows-1251, редактор нескольких значений, группы, дубли, ручное объединение и undo. Экспорт JSON/CSV/VCF; снимок телефона хранится отдельно. **Запись контактов на телефон пока не реализована.** |
| SMS, календарь, задачи | Нативное чтение через поддерживаемый USB OBEX/PCCS или COM/PDU, поиск и экспорт. Отправка SMS, удаление и синхронизация не реализованы. |
| TLS / HTTPS | Проверка официальных MBedTLS 1.4.4 и SSL v21 по закреплённым хешам, кэш, передача SIS, ручная установка/восстановление, проверка часов и экспорт отчёта. Qt и EKA1 имеют отдельные ограничения; системный DLL автоматически не заменяется. |
| Подготовка E72 | Мастер с сохраняемым прогрессом для телефона/прошивки/транспорта/драйверов. Начальный профиль E72-1 / RM-530 / 054.005 — ввод владельца, а не обнаруженный факт. |
| Приложения и сертификаты | 40 локальных карточек каталога, библиотека SIS/SISX/JAR/JAD, инспектор структуры/подписей/совместимости, проверка и передача публичного сертификата. Каталог ничего автоматически не скачивает и не устанавливает. |
| Копии, медиа и темы | Файловые backup → verify → restore-plan, восстановление новых файлов; FFmpeg-пресеты, рингтоны, анализ/просмотр тем S60. Полный редактор/сборка тем пока не реализованы. |
| Phone Agent / Device Lab | Инструкция запуска ADBian и отдельная экспериментальная панель с arming/подтверждением команд. Полная сборка собственного SIS-агента и agent-side PIM остаются в работе. |

Светлая тема включена по умолчанию; переключатель в шапке сохраняет выбор. Есть
RU/EN, режимы пользователя/разработчика и цветные акценты навигации.

Наличие кода и зелёный CI **не означают аппаратную поддержку конкретной прошивки**.
Приёмка текущего Rust-адаптера на физической E72 ещё не завершена. Непроверенные
операции отображаются отдельно от подтверждённых; неясные записи не повторяются.
[Полный аудит issues и оставшиеся задачи](docs/ISSUE_AUDIT.md).

## Подключение телефона

- **Bluetooth / файлы:** сопрягите Nokia в Windows, установите и запустите rshelld
  на телефоне по [инструкции агента](docs/agent/WINDOWS_E72_CHECK.md). В YESKIA
  выберите Bluetooth-маршрут телефона и нажмите «Подключить». Обновление списка
  не выполняет SDP/RFCOMM-подключений ко всем устройствам.
- **USB / PIM:** выберите PC Suite на телефоне, освободите занятый COM/OBEX-канал,
  подключитесь и используйте «Прочитать телефон» в нужном разделе.
- **USB / файлы:** MTP/WPD даёт чтение, накопитель — доступ к связанному тому.
  Режим USB показан отдельно от Bluetooth. При ошибке используйте «Диагностику».

Драйверы не устанавливаются автоматически. Sideload SIS/JAR — передача файла;
установку завершает пользователь на телефоне. Файловая копия не заменяет PIM
и полный системный backup.

## Разработка и следующий релиз

На Windows нужны Node.js 22, Rust stable MSVC, C++ Build Tools и WebView2.

```bash
npm ci
npm run tauri dev
npm run release:check
npm run release:test
bash scripts/package.sh
# dist-release/YESKIA_0.5.0_x64-setup.exe
```

Упаковка явно выбирает `x86_64-pc-windows-msvc` и `yeskia-app`. Проверяются версии
Cargo/npm/Tauri, свежий AMD64 GUI EXE, точное совпадение установленного приложения
со сборкой, runtime-версия, переустановка и сохранение данных. Старый EXE не может
подменить отсутствующий результат сборки. Ручной workflow
[Release artifacts](https://github.com/grayhex/YESKIA/actions/workflows/release.yml)
проверяет ожидаемую версию и собирает тот же установщик; публикации релиза нет.
